# 🔗 URL Shortener using FastAPI

A simple **URL Shortener backend** built with **Python & FastAPI**.  
This project converts long URLs into short URLs and redirects them back to the original URL.

---

## 🚀 Features
- Shorten any long URL (Google, YouTube, etc.)
- Redirect short URL to original URL
- FastAPI backend
- Swagger UI for API testing
- Easy to run locally
